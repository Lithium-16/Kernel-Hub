# PetLink Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build PetLink: a relay module on Pluto (`modules/petlink`) and a Windows desktop-pet client (`crates/petlink` → `petlink.exe`) that lets two friends' pets carry mail, peek and visit through a taskbar door.

**Architecture:** The relay is a Kernel module in Python/aiohttp (same shape as `modules/party`): token-authenticated WebSocket hub + file store in SQLite, shared over Tailscale Funnel on a path. The client is one Rust binary built on eframe/egui: a transparent, always-on-top, click-through overlay for the pets and door, egui viewports for the mail and lens windows, a tray icon, a tokio network thread, and self-update from this repo's `node-build-N` GitHub releases.

**Tech Stack:** Python 3 + aiohttp + sqlite3 + kernel_sdk; Rust 1.94 (edition 2024) + eframe/egui, tray-icon, tokio-tungstenite, reqwest, image, xcap, rfd, windows crate.

**Spec:** `docs/petlink-design.md` (read it before any task).

## Global Constraints

- Relay listens only on `127.0.0.1:8098`; reached through Tailscale Funnel at `--https=10000 --set-path=/petlink`.
- Tokens: 32 random bytes, shown once, stored as SHA-256 hex. Bad/missing `hello` → WebSocket close code `4401`.
- Message envelope: `{ "v": 1, "id": "<ulid>", "kind": ..., "from": ..., "to": ... }`; the relay always overwrites `from` with the authenticated user.
- Upload limit 100 MB per file; 200 MB uploads per user per hour; 30 messages per user per minute; file store refuses uploads past 2 GB.
- Files deleted after the recipient downloads them, or after 7 days. Undelivered mail expires after 30 days.
- Peek is off by default; the relay refuses to forward `peek.request` while the target's stored toggle is off.
- Client: Windows-only code behind `#[cfg(windows)]`; the crate must build, test and pass `cargo clippy --workspace --all-targets -- -D warnings` on Ubuntu and Windows.
- The workspace lint is `unsafe_code = "forbid"`. `crates/petlink` does **not** inherit workspace lints; it sets `unsafe_code = "deny"` and only `src/win.rs` has `#![allow(unsafe_code)]`.
- Client config: `%APPDATA%\PetLink\config.toml` (`relay_url`, `token`, `scale`); logs in `%APPDATA%\PetLink\logs\`; saved files in `Downloads\PetLink\`.
- Self-update only from GitHub Releases of `Lithium-16/Kernel-Hub` (`node-build-N` with `petlink-windows-x64.exe` + `.sha256`), checked at start and every 6 h. A dev build (`PETLINK_BUILD` unset) never self-updates.
- Pixel art scaled with nearest-neighbour, default ×2 (setting 1–4).
- Python module files are named `pet*.py` (module dirs share one `sys.path` in pytest; names must not clash with other modules).
- No text in code comments or commit messages in the Kernel persona; plain professional English.

## Review Focus

1. **Party and PetLink share Funnel port 10000.** Party's `share.stop` must not take PetLink down (and vice versa). Expected: each module's off command only removes its own path. → Test in Task 1.
2. **Duplicate login** (the same token connects twice, e.g. an old client still running). Expected: the new socket wins, the old one is closed with `4409`, and the old socket's cleanup does not mark the user offline. → Test in Task 3.
3. **Interrupted file download.** Expected: the file is only deleted after a complete download, so a retry works. → Test in Task 3.
4. **Mail with a `file_id` the sender doesn't own or that doesn't exist.** Expected: refused with `error {code: "bad_file"}`, nothing queued. → Test in Task 3.
5. **The client restarted while mail was waiting to be sent (outbox) or while the relay was down.** Expected: the outbox survives on disk and is flushed after reconnect, exactly once per `mail_id`. → Test in Task 9 (outbox) and Task 3 (relay ignores a repeated `mail_id`).

    if funnel:

    assert sharing_from(both, DNS, 10000, 8097) == "public"

class PathTailscale:
    """Keeps handlers per path, like the real `tailscale serve`."""

    def __init__(self):
        self.calls, self.handlers, self.funnel = [], {}, False

    def __call__(self, cmd, cwd=None, timeout=0, env=None):
        args = cmd[1:]
        self.calls.append(args)
        if args[:2] == ["status", "--json"]:
            return Ran(0, json.dumps({"Self": {"DNSName": DNS + "."}}))
        if args[:3] == ["serve", "status", "--json"]:
            return Ran(0, json.dumps(status(self.handlers, self.funnel) if self.handlers else {}))

        if args[-1] == "off":
            self.handlers.pop(path, None)
            return Ran(0, "")
        self.handlers[path] = int(args[-1].rsplit(":", 1)[1])
        self.funnel = args[0] == "funnel"
        return Ran(0, "ok")

def share_url(dns_name: str, port: int, path: str = "/") -> str:
    host = dns_name.rstrip(".")
    base = f"https://{host}" if port == 443 else f"https://{host}:{port}"
    return base if path == "/" else base + path


def sharing_from(serve_status: dict[str, Any], dns_name: str, https_port: int, game_port: int, path: str = "/") -> str:
    """'public', 'tailnet' or 'off', from `tailscale serve status --json`."""
    key = f"{dns_name.rstrip('.')}:{https_port}"
    handlers = ((serve_status.get("Web") or {}).get(key) or {}).get("Handlers") or {}
    proxy = str((handlers.get(path) or {}).get("Proxy", ""))
    if not re.search(rf"(127\.0\.0\.1|localhost):{game_port}/?$", proxy):
        return "off"
    return "public" if (serve_status.get("AllowFunnel") or {}).get(key) else "tailnet"

```python
"""PetLink's SQLite store: users and tokens, the peek toggle, queued mail and uploaded files."""

import hashlib
import json
import secrets
import sqlite3
import time
from collections.abc import Callable
from dataclasses import dataclass
from pathlib import Path

FILE_TTL_S = 7 * 86400
MAIL_TTL_S = 30 * 86400

SCHEMA = """
CREATE TABLE IF NOT EXISTS users (
  id TEXT PRIMARY KEY, name TEXT NOT NULL, bow_hue INTEGER NOT NULL,
  token_hash TEXT NOT NULL UNIQUE, peek INTEGER NOT NULL DEFAULT 0);
CREATE TABLE IF NOT EXISTS mail (
  id TEXT PRIMARY KEY, sender TEXT NOT NULL, recipient TEXT NOT NULL,
  message TEXT NOT NULL, created REAL NOT NULL, delivered INTEGER NOT NULL DEFAULT 0);
CREATE TABLE IF NOT EXISTS files (
  id TEXT PRIMARY KEY, owner TEXT NOT NULL, recipient TEXT NOT NULL, name TEXT NOT NULL,
  size INTEGER NOT NULL, path TEXT NOT NULL, created REAL NOT NULL);
"""


def _hash(token: str) -> str:
    return hashlib.sha256(token.encode()).hexdigest()


@dataclass(frozen=True)
class User:
    id: str
    name: str
    bow_hue: int
    peek: bool


@dataclass(frozen=True)
class FileRow:
    id: str
    owner: str
    to: str
    name: str
    size: int
    path: Path
    created: float


class Store:
    def __init__(self, path: Path, clock: Callable[[], float] = time.time) -> None:
        path.parent.mkdir(parents=True, exist_ok=True)
        self.db = sqlite3.connect(path, isolation_level=None, check_same_thread=False)
        self.db.executescript(SCHEMA)
        self.clock = clock

    # -- users ----------------------------------------------------------------------------

    @staticmethod
    def _user(row: tuple | None) -> User | None:
        return User(row[0], row[1], row[2], bool(row[3])) if row else None

    def add_user(self, name: str, bow_hue: int) -> tuple[User, str]:
        token = secrets.token_urlsafe(32)
        user = User("u_" + secrets.token_hex(4), name, bow_hue % 360, False)
        self.db.execute(
            "INSERT INTO users (id, name, bow_hue, token_hash) VALUES (?, ?, ?, ?)",
            (user.id, user.name, user.bow_hue, _hash(token)),
        )
        return user, token

    def remove_user(self, user_id: str) -> bool:
        return self.db.execute("DELETE FROM users WHERE id = ?", (user_id,)).rowcount > 0

    def users(self) -> list[User]:
        rows = self.db.execute("SELECT id, name, bow_hue, peek FROM users ORDER BY name").fetchall()
        return [User(r[0], r[1], r[2], bool(r[3])) for r in rows]

    def user(self, user_id: str) -> User | None:
        return self._user(self.db.execute("SELECT id, name, bow_hue, peek FROM users WHERE id = ?", (user_id,)).fetchone())

    def auth(self, token: str) -> User | None:
        if not token:
            return None
        row = self.db.execute("SELECT id, name, bow_hue, peek FROM users WHERE token_hash = ?", (_hash(token),)).fetchone()
        return self._user(row)

    def set_peek(self, user_id: str, on: bool) -> None:
        self.db.execute("UPDATE users SET peek = ? WHERE id = ?", (int(on), user_id))

    # -- mail -----------------------------------------------------------------------------

    def queue_mail(self, mail_id: str, sender: str, to: str, message: dict) -> bool:
        cur = self.db.execute(
            "INSERT OR IGNORE INTO mail (id, sender, recipient, message, created) VALUES (?, ?, ?, ?, ?)",
            (mail_id, sender, to, json.dumps(message), self.clock()),
        )
        return cur.rowcount > 0

    def pending_mail(self, to: str) -> list[dict]:
        rows = self.db.execute(
            "SELECT message FROM mail WHERE recipient = ? AND delivered = 0 ORDER BY created", (to,)
        ).fetchall()
        return [json.loads(r[0]) for r in rows]

    def mail_delivered(self, mail_id: str) -> None:
        # The row stays (until it expires) so a client re-sending the same mail_id after a
        # restart doesn't get it delivered twice.
        self.db.execute("UPDATE mail SET delivered = 1, message = '{}' WHERE id = ?", (mail_id,))

    def mail_state(self, mail_id: str) -> str | None:
        row = self.db.execute("SELECT delivered FROM mail WHERE id = ?", (mail_id,)).fetchone()
        return None if row is None else ("delivered" if row[0] else "queued")

    # -- files ----------------------------------------------------------------------------

    def add_file(self, file_id: str, owner: str, to: str, name: str, size: int, path: Path) -> None:
        self.db.execute(
            "INSERT INTO files (id, owner, recipient, name, size, path, created) VALUES (?, ?, ?, ?, ?, ?, ?)",
            (file_id, owner, to, name, size, str(path), self.clock()),
        )

    def file(self, file_id: str) -> FileRow | None:
        r = self.db.execute(
            "SELECT id, owner, recipient, name, size, path, created FROM files WHERE id = ?", (file_id,)
        ).fetchone()
        return FileRow(r[0], r[1], r[2], r[3], r[4], Path(r[5]), r[6]) if r else None

    def drop_file(self, file_id: str) -> None:
        self.db.execute("DELETE FROM files WHERE id = ?", (file_id,))

    def files_size(self) -> int:
        return int(self.db.execute("SELECT COALESCE(SUM(size), 0) FROM files").fetchone()[0])

    def expire(self, now: float) -> list[Path]:
        old = self.db.execute("SELECT id, path FROM files WHERE created < ?", (now - FILE_TTL_S,)).fetchall()
        self.db.execute("DELETE FROM files WHERE created < ?", (now - FILE_TTL_S,))
        self.db.execute("DELETE FROM mail WHERE created < ?", (now - MAIL_TTL_S,))
        return [Path(p) for _, p in old]
```

```python
"""PetLink's relay: one WebSocket per user, routing by `to`, queued mail and a small file store."""

import asyncio
import json
import logging
import re
import secrets
import time
from collections import deque
from collections.abc import Callable
from pathlib import Path
from typing import Any

from aiohttp import WSCloseCode, WSMsgType, web
from petstore import Store, User

PROTOCOL = 1
FILE_ID = re.compile(r"^[A-Za-z0-9_-]{8,64}$")
ROUTED = {"mail", "mail.read", "peek.request", "peek.result", "visit.start", "visit.end", "touch"}
CLOSE_AUTH, CLOSE_REPLACED, CLOSE_UPGRADE = 4401, 4409, 4426
CHUNK = 256 * 1024


def ulid() -> str:
    # ponytail: random id, not a real time-ordered ULID; nothing sorts by it.
    return "01" + secrets.token_hex(12).upper()


class Relay:
    def __init__(
        self,
        store: Store,
        files_dir: Path,
        *,
        clock: Callable[[], float] = time.time,
        log: logging.Logger | None = None,
        max_file: int = 100 * 2**20,
        hourly_upload: int = 200 * 2**20,
        store_limit: int = 2 * 2**30,
        per_minute: int = 30,
    ) -> None:
        self.store, self.files_dir, self.clock = store, files_dir, clock
        self.log = log or logging.getLogger("petlink")
        self.max_file, self.hourly_upload, self.store_limit, self.per_minute = max_file, hourly_upload, store_limit, per_minute
        files_dir.mkdir(parents=True, exist_ok=True)
        self.sockets: dict[str, web.WebSocketResponse] = {}
        self.presence: dict[str, str] = {}
        self.visits: dict[str, str] = {}  # visitor -> host
        self.sent: dict[str, deque[float]] = {}
        self.uploaded: dict[str, deque[tuple[float, int]]] = {}

    def app(self) -> web.Application:
        app = web.Application(client_max_size=self.max_file + 1)
        for prefix in ("", "/petlink"):
            app.router.add_get(f"{prefix}/ws", self.ws)
            app.router.add_put(f"{prefix}/files/{{id}}", self.put_file)
            app.router.add_get(f"{prefix}/files/{{id}}", self.get_file)
        return app

    def online(self) -> list[str]:
        return list(self.sockets)

    # -- sending ---------------------------------------------------------------------------

    def _envelope(self, kind: str, to: str, sender: str = "", **body: Any) -> dict[str, Any]:
        return {"v": PROTOCOL, "id": ulid(), "kind": kind, "from": sender, "to": to, **body}

    async def _send(self, user_id: str, message: dict[str, Any]) -> bool:
        ws = self.sockets.get(user_id)
        if ws is None or ws.closed:
            return False
        try:
            await ws.send_json(message)
            return True
        except (ConnectionResetError, RuntimeError):
            return False

    async def _error(self, user_id: str, code: str, text: str, ref: str = "") -> None:
        await self._send(user_id, self._envelope("error", user_id, code=code, message=text, ref=ref))

    async def _broadcast(self, sender: str, message: dict[str, Any]) -> None:
        for user in self.store.users():
            if user.id != sender:
                await self._send(user.id, {**message, "to": user.id})

    async def _flush_mail(self, user_id: str) -> None:
        for m in self.store.pending_mail(user_id):
            if not await self._send(user_id, m):
                return
            self.store.mail_delivered(m["mail_id"])
            await self._send(m["from"], self._envelope("delivered", m["from"], mail_id=m["mail_id"]))

    # -- the socket ------------------------------------------------------------------------

    def _welcome(self, me: User) -> dict[str, Any]:
        friends = [
            {"id": u.id, "name": u.name, "bow_hue": u.bow_hue, "peek": u.peek, "online": u.id in self.sockets}
            for u in self.store.users()
            if u.id != me.id
        ]
        return self._envelope(
            "welcome", me.id, me={"id": me.id, "name": me.name, "bow_hue": me.bow_hue, "peek": me.peek}, friends=friends
        )

    async def ws(self, request: web.Request) -> web.WebSocketResponse:
        ws = web.WebSocketResponse(heartbeat=30, max_msg_size=1 << 20)
        await ws.prepare(request)
        try:
            first = await asyncio.wait_for(ws.receive_json(), 10)
        except (TimeoutError, ValueError, TypeError):
            await ws.close(code=CLOSE_AUTH)
            return ws
        user = self.store.auth(str(first.get("token", ""))) if first.get("kind") == "hello" else None
        if user is None:
            await ws.close(code=CLOSE_AUTH)
            return ws
        if first.get("v") != PROTOCOL:
            await ws.send_json(self._envelope("error", user.id, code="upgrade", message="please update PetLink", ref=""))
            await ws.close(code=CLOSE_UPGRADE)
            return ws
        old = self.sockets.get(user.id)
        self.sockets[user.id] = ws
        if old is not None:
            await old.close(code=CLOSE_REPLACED)
        self.presence[user.id] = "online"
        await ws.send_json(self._welcome(user))
        await self._broadcast(user.id, self._envelope("presence", "", user.id, state="online"))
        await self._flush_mail(user.id)
        try:
            async for raw in ws:
                if raw.type != WSMsgType.TEXT:
                    continue
                try:
                    data = json.loads(raw.data)
                    if not isinstance(data, dict):
                        raise ValueError
                except ValueError:
                    await self._error(user.id, "bad_json", "not a JSON object")
                    continue
                await self._handle(user, data)
        finally:
            if self.sockets.get(user.id) is ws:  # not replaced by a newer login
                await self._gone(user.id)
        return ws

    async def _gone(self, user_id: str) -> None:
        del self.sockets[user_id]
        self.presence[user_id] = "offline"
        for visitor, host in list(self.visits.items()):
            if user_id in (visitor, host):
                del self.visits[visitor]
                other = host if visitor == user_id else visitor
                await self._send(other, self._envelope("visit.end", other, user_id))
        await self._broadcast(user_id, self._envelope("presence", "", user_id, state="offline"))

    def _limited(self, user_id: str) -> bool:
        now = self.clock()
        q = self.sent.setdefault(user_id, deque())
        while q and q[0] < now - 60:
            q.popleft()
        q.append(now)
        return len(q) > self.per_minute

    async def _handle(self, user: User, data: dict[str, Any]) -> None:
        if self._limited(user.id):
            await self._error(user.id, "rate_limited", "slow down", str(data.get("id", "")))
            return
        data["from"] = user.id
        data["v"] = PROTOCOL
        kind, ref = data.get("kind"), str(data.get("id", ""))
        if kind == "presence" and data.get("state") in ("online", "away"):
            self.presence[user.id] = data["state"]
            await self._broadcast(user.id, data)
            return
        if kind == "peek.allow":
            self.store.set_peek(user.id, bool(data.get("on")))
            await self._broadcast(user.id, {**data, "on": bool(data.get("on"))})
            return
        if kind not in ROUTED:
            await self._error(user.id, "bad_kind", f"unknown kind {kind!r}", ref)
            return
        to = str(data.get("to", ""))
        if to == user.id or self.store.user(to) is None:
            await self._error(user.id, "bad_target", "no such friend", ref)
            return
        if kind == "mail":
            await self._mail(user, to, data, ref)
            return
        if kind == "peek.request" and not self.store.user(to).peek:
            await self._send(user.id, self._envelope("peek.result", user.id, to, peek_id=data.get("peek_id"), file_id="", denied=True))
            return
        if kind == "visit.start":
            self.visits[user.id] = to
        elif kind == "visit.end":
            self.visits.pop(user.id, None)
            if self.visits.get(to) == user.id:
                del self.visits[to]
        if not await self._send(to, data):
            await self._error(user.id, "offline", "your friend is offline", ref)

    async def _mail(self, user: User, to: str, data: dict[str, Any], ref: str) -> None:
        mail_id = str(data.get("mail_id", ""))
        files = data.get("files") or []
        if not mail_id or not isinstance(files, list):
            await self._error(user.id, "bad_mail", "mail needs a mail_id", ref)
            return
        for f in files:
            row = self.store.file(str((f or {}).get("file_id", "")))
            if row is None or row.owner != user.id or row.to != to:
                await self._error(user.id, "bad_file", "a file in this mail wasn't uploaded for this friend", ref)
                return
        if self.store.queue_mail(mail_id, user.id, to, data):
            await self._flush_mail(to)
        elif self.store.mail_state(mail_id) == "delivered":
            # A re-send after the sender missed the first `delivered` (it was offline then).
            await self._send(user.id, self._envelope("delivered", user.id, mail_id=mail_id))

    # -- files ------------------------------------------------------------------------------

    def _bearer(self, request: web.Request) -> User | None:
        auth = request.headers.get("Authorization", "")
        return self.store.auth(auth[7:]) if auth.startswith("Bearer ") else None

    def _quota_left(self, user_id: str) -> int:
        now = self.clock()
        q = self.uploaded.setdefault(user_id, deque())
        while q and q[0][0] < now - 3600:
            q.popleft()
        return self.hourly_upload - sum(n for _, n in q)

    async def put_file(self, request: web.Request) -> web.Response:
        user = self._bearer(request)
        if user is None:
            return web.Response(status=401)
        file_id, to, name = request.match_info["id"], request.query.get("to", ""), request.query.get("name", "")
        if not FILE_ID.match(file_id) or not name or self.store.user(to) is None or to == user.id:
            return web.Response(status=400, text="bad file id, name or recipient")
        if self.store.file(file_id) is not None:
            return web.Response(status=409)
        size = request.content_length
        if size is None or size > self.max_file:
            return web.Response(status=413)
        if size > self._quota_left(user.id):
            return web.Response(status=429)
        if self.store.files_size() + size > self.store_limit:
            return web.Response(status=507)
        path = self.files_dir / file_id
        written = 0
        with path.open("wb") as out:
            async for chunk in request.content.iter_chunked(CHUNK):
                written += len(chunk)
                if written > self.max_file:
                    out.close()
                    path.unlink(missing_ok=True)
                    return web.Response(status=413)
                out.write(chunk)
        self.store.add_file(file_id, user.id, to, name[:200], written, path)
        self.uploaded[user.id].append((self.clock(), written))
        return web.Response(status=201)

    async def _stream_file(self, request: web.Request, path: Path) -> web.StreamResponse:
        resp = web.StreamResponse(headers={"Content-Type": "application/octet-stream"})
        resp.content_length = path.stat().st_size
        await resp.prepare(request)
        with path.open("rb") as f:
            while chunk := f.read(CHUNK):
                await resp.write(chunk)
        await resp.write_eof()
        return resp

    async def get_file(self, request: web.Request) -> web.StreamResponse:
        user = self._bearer(request)
        if user is None:
            return web.Response(status=401)
        row = self.store.file(request.match_info["id"])
        if row is None or not row.path.exists():
            return web.Response(status=404)
        if row.to != user.id:
            return web.Response(status=403)
        try:
            resp = await self._stream_file(request, row.path)
        except (ConnectionResetError, asyncio.CancelledError):
            self.log.info("download of %s interrupted; keeping it", row.id)
            raise web.HTTPInternalServerError() from None
        self.store.drop_file(row.id)
        row.path.unlink(missing_ok=True)
        return resp

    def cleanup(self) -> int:
        paths = self.store.expire(self.clock())
        for p in paths:
            p.unlink(missing_ok=True)
        return len(paths)
```

Note: `asyncio.CancelledError` must not be swallowed in general; here it's re-raised as an HTTP error only to keep the file. If a reviewer prefers, catch only `ConnectionResetError` and let `CancelledError` propagate (the file is kept either way because `drop_file` is never reached).

```python
"""PetLink on Kernel's side: runs the relay, manages friends and shares it through Tailscale."""

import asyncio
import base64
import json
import logging
from pathlib import Path
from typing import Any

from aiohttp import web
from kernel_sdk import ActionError
from kernel_sdk.webgame import TailscaleShare, run_command
from petrelay import Relay
from petstore import Store

CLEANUP_S = 3600


class PetLink(TailscaleShare):
    def __init__(self, settings: dict[str, Any], data_dir: Path, *, emit=None, log: logging.Logger | None = None, run=run_command) -> None:
        super().__init__("PetLink", settings, int(settings.get("port", 8098)), emit=emit, log=log, run=run,
                         path=str(settings.get("share_path", "/petlink")))
        self.store = Store(data_dir / "petlink.db")
        self.relay = Relay(self.store, data_dir / "files", log=self.log)
        self.state = "stopped"

    async def run_forever(self) -> None:
        runner = web.AppRunner(self.relay.app())
        await runner.setup()
        await web.TCPSite(runner, "127.0.0.1", self.port).start()
        self.state = "running"
        await asyncio.to_thread(self.refresh_sharing)
        try:
            while True:
                removed = self.relay.cleanup()
                if removed:
                    self.log.info("removed %d expired files", removed)
                await asyncio.sleep(CLEANUP_S)
        finally:
            self.state = "stopped"
            await runner.cleanup()

    def _relay_url(self) -> str:
        if not self.link:
            raise ActionError("disabled", "Share PetLink first, so the invite has an address that works from outside.")
        return "wss://" + self.link.removeprefix("https://").rstrip("/") + "/ws"

    async def add_user(self, name: str, bow_hue: int = 0) -> dict[str, Any]:
        name = name.strip()
        if not name or any(u.name.lower() == name.lower() for u in self.store.users()):
            raise ActionError("invalid_params", "pick a name that isn't empty or taken")
        relay_url = self._relay_url()
        user, token = self.store.add_user(name, bow_hue)
        blob = base64.urlsafe_b64encode(json.dumps({"relay_url": relay_url, "token": token}).encode()).decode().rstrip("=")
        self.emit("user.added", f"{name} was added to PetLink")
        return {"user": user.id, "invite": f"petlink:{blob}"}

    async def remove_user(self, name: str) -> dict[str, Any]:
        user = next((u for u in self.store.users() if u.name.lower() == name.strip().lower()), None)
        if user is None:
            raise ActionError("invalid_params", f"no friend called {name!r}")
        self.store.remove_user(user.id)
        ws = self.relay.sockets.get(user.id)
        if ws is not None:
            await ws.close(code=4401)
        return {"removed": user.name}

    def snapshot(self) -> dict[str, Any]:
        online = set(self.relay.online())
        return {
            "state": self.state,
            "sharing": self.sharing,
            "link": self.link,
            "users": [{"id": u.id, "name": u.name, "online": u.id in online, "peek": u.peek} for u in self.store.users()],
            "files_mb": round(self.store.files_size() / 2**20, 1),
        }
```

//! The client's settings: %APPDATA%\PetLink\config.toml, first filled from an invite.

use anyhow::{Context, bail};
use base64::Engine;
use serde::{Deserialize, Serialize};
use std::path::{Path, PathBuf};

fn default_scale() -> u8 {
    2
}

#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
pub struct Config {
    pub relay_url: String,
    pub token: String,
    #[serde(default = "default_scale")]
    pub scale: u8,
}

#[derive(Deserialize)]
struct Invite {
    relay_url: String,
    token: String,
}

impl Config {
    pub fn dir() -> PathBuf {
        std::env::var_os("APPDATA").map(PathBuf::from).unwrap_or_else(std::env::temp_dir).join("PetLink")
    }

    pub fn load(dir: &Path) -> anyhow::Result<Option<Config>> {
        let path = dir.join("config.toml");
        if !path.exists() {
            return Ok(None);
        }
        let text = std::fs::read_to_string(&path).with_context(|| format!("reading {}", path.display()))?;
        let mut c: Config = toml::from_str(&text).with_context(|| format!("parsing {}", path.display()))?;
        c.scale = c.scale.clamp(1, 4);
        Ok(Some(c))
    }

    pub fn save(&self, dir: &Path) -> anyhow::Result<()> {
        std::fs::create_dir_all(dir)?;
        std::fs::write(dir.join("config.toml"), toml::to_string(self)?)?;
        Ok(())
    }

    pub fn from_invite(invite: &str) -> anyhow::Result<Config> {
        let Some(blob) = invite.trim().strip_prefix("petlink:") else {
            bail!("that isn't a PetLink invite (it starts with petlink:)");
        };
        let bytes = base64::engine::general_purpose::URL_SAFE_NO_PAD
            .decode(blob.trim_end_matches('='))
            .context("the invite is damaged")?;
        let i: Invite = serde_json::from_slice(&bytes).context("the invite is damaged")?;
        Ok(Config { relay_url: i.relay_url, token: i.token, scale: default_scale() })
    }

    pub fn files_url(&self) -> String {
        let http = self.relay_url.replacen("wss://", "https://", 1).replacen("ws://", "http://", 1);
        format!("{}/files", http.trim_end_matches("/ws"))
    }
}

fn decode(bytes: &[u8], name: &str) -> anyhow::Result<Rgba> {
    Ok(image::load_from_memory(bytes).with_context(|| format!("decoding {name}"))?.to_rgba8())
}

fn hsv(r: u8, g: u8, b: u8) -> (f32, f32, f32) {
    let (r, g, b) = (r as f32 / 255.0, g as f32 / 255.0, b as f32 / 255.0);
    let max = r.max(g).max(b);
    let d = max - r.min(g).min(b);
    let h = if d == 0.0 {
        0.0
    } else if max == r {
        60.0 * ((g - b) / d).rem_euclid(6.0)
    } else if max == g {
        60.0 * ((b - r) / d + 2.0)
    } else {
        60.0 * ((r - g) / d + 4.0)
    };
    (h, if max == 0.0 { 0.0 } else { d / max }, max)
}

fn rgb(h: f32, s: f32, v: f32) -> (u8, u8, u8) {
    let c = v * s;
    let x = c * (1.0 - ((h / 60.0).rem_euclid(2.0) - 1.0).abs());
    let (r, g, b) = match (h / 60.0) as u32 % 6 {
        0 => (c, x, 0.0),
        1 => (x, c, 0.0),
        2 => (0.0, c, x),
        3 => (0.0, x, c),
        4 => (x, 0.0, c),
        _ => (c, 0.0, x),
    };
    let m = v - c;
    let f = |u: f32| ((u + m) * 255.0).round() as u8;
    (f(r), f(g), f(b))
}

/// The bows and chest ribbon: saturated reds (checked against walk.png: skin, eyes and the
/// inner ears stay below 0.6 saturation).
pub fn is_bow(r: u8, g: u8, b: u8) -> bool {
    let (h, s, _) = hsv(r, g, b);
    s >= 0.6 && !(15.0..340.0).contains(&h)
}

pub fn recolor_bows(img: &mut Rgba, hue: u16) -> usize {
    if hue % 360 == 0 {
        return 0;
    }
    let mut n = 0;
    for p in img.pixels_mut() {
        if p[3] == 0 || !is_bow(p[0], p[1], p[2]) {
            continue;
        }
        let (_, s, v) = hsv(p[0], p[1], p[2]);
        let (r, g, b) = rgb(f32::from(hue % 360), s, v);
        *p = Px([r, g, b, p[3]]);
        n += 1;
    }
    n
}

pub fn mirror(img: &Rgba) -> Rgba {
    image::imageops::flip_horizontal(img)
}

/// Puts a 64x64 walk cell on the 32x48 canvas the pose images use, feet on the bottom row.
pub fn trim_to(cell: &Rgba, w: u32, h: u32) -> Rgba {
    let bottom = (0..cell.height()).rev().find(|&y| (0..cell.width()).any(|x| cell.get_pixel(x, y)[3] > 0)).unwrap_or(cell.height() - 1);
    let mut out = Rgba::new(w, h);
    let x0 = (cell.width() - w) / 2;
    let y0 = (bottom + 1).saturating_sub(h);
    image::imageops::overlay(&mut out, &image::imageops::crop_imm(cell, x0, y0, w, h).to_image(), 0, 0);
    out
}

impl Sprites {
    pub fn load(bow_hue: u16) -> anyhow::Result<Sprites> {
        let sheet = decode(WALK, "walk.png")?;
        let mut s = Sprites {
            walk: (0..8)
                .map(|i| trim_to(&image::imageops::crop_imm(&sheet, i * CELL, WALK_ROW * CELL, CELL, CELL).to_image(), POSE_W, POSE_H))
                .collect(),
            idle: decode(IDLE, "idle.png")?,
            sit: decode(SIT, "sit.png")?,
            sleep: decode(SLEEP, "sleep.png")?,
            carry: decode(CARRY, "carry.png")?,
            parcel: decode(PARCEL, "parcel.png")?,
        };
        for img in s.walk.iter_mut().chain([&mut s.idle, &mut s.sit, &mut s.sleep, &mut s.carry]) {
            recolor_bows(img, bow_hue);
        }
        Ok(s)
    }

    pub fn pose(&self, p: Pose) -> &Rgba {
        match p {
            Pose::Idle => &self.idle,
            Pose::Sit => &self.sit,
            Pose::Sleep => &self.sleep,
            Pose::Carry => &self.carry,
        }
    }
}

//! Where pets can stand: the taskbar and the uncovered top edges of windows.

#[derive(Debug, Clone, Copy, PartialEq)]
pub struct Rect {
    pub x: f32,
    pub y: f32,
    pub w: f32,
    pub h: f32,
}

impl Rect {
    pub fn right(&self) -> f32 {
        self.x + self.w
    }
    pub fn contains(&self, x: f32, y: f32) -> bool {
        x >= self.x && x < self.right() && y >= self.y && y < self.y + self.h
    }
}

#[derive(Debug, Clone, Copy, PartialEq)]
pub struct Floor {
    pub x0: f32,
    pub x1: f32,
    pub y: f32,
}

pub struct World {
    pub screen: Rect,
    pub taskbar_top: f32,
    pub floors: Vec<Floor>,
    pub door_x: f32,
}

const MIN_WINDOW_W: f32 = 120.0;
const TOP_MARGIN: f32 = 40.0;
const DOOR_GAP: f32 = 40.0;

/// Subtracts [a, b) from every span.
fn cut(spans: Vec<(f32, f32)>, a: f32, b: f32) -> Vec<(f32, f32)> {
    spans
        .into_iter()
        .flat_map(|(x0, x1)| {
            if b <= x0 || a >= x1 {
                vec![(x0, x1)]
            } else {
                [(x0, a), (b, x1)].into_iter().filter(|(l, r)| r - l >= 1.0).collect()
            }
        })
        .collect()
}

impl World {
    /// `windows` front-most first.
    pub fn build(screen: Rect, taskbar: Option<Rect>, windows: &[Rect], tray_left: f32) -> World {
        let ground = taskbar.map_or(screen.y + screen.h, |t| t.y);
        let mut floors = vec![Floor { x0: screen.x, x1: screen.right(), y: ground }];
        for (i, w) in windows.iter().enumerate() {
            if w.w < MIN_WINDOW_W || w.y < screen.y + TOP_MARGIN || w.y >= ground {
                continue;
            }
            let mut spans = vec![(w.x.max(screen.x), w.right().min(screen.right()))];
            for front in &windows[..i] {
                if w.y >= front.y && w.y < front.y + front.h {
                    spans = cut(spans, front.x, front.right());
                }
            }
            floors.extend(spans.into_iter().map(|(x0, x1)| Floor { x0, x1, y: w.y }));
        }
        let door_x = (tray_left - DOOR_GAP).clamp(screen.x + 20.0, screen.right() - 20.0);
        World { screen, taskbar_top: ground, floors, door_x }
    }

    pub fn ground(&self) -> f32 {
        self.taskbar_top
    }

    pub fn floor_below(&self, x: f32, y: f32) -> Option<f32> {
        self.floors
            .iter()
            .filter(|f| x >= f.x0 && x < f.x1 && f.y >= y - 1.0)
            .map(|f| f.y)
            .min_by(f32::total_cmp)
    }
}

//! One pet: a small state machine with gravity. Pure logic; app.rs draws it.

use crate::world::{Rect, World};
use rand::Rng;

pub const WALK_SPEED: f32 = 40.0;
const GRAVITY: f32 = 1400.0;
const BOUNCE: f32 = 0.45;
const PAT_S: f32 = 0.6;
const DIZZY_S: f32 = 1.5;
const PEEK_S: f32 = 2.0;
const HALF_W: f32 = 16.0;
const FRAME_S: f32 = 0.1;

#[derive(Debug, Clone, Copy, PartialEq)]
pub enum State {
    Idle,
    Wander { to_x: f32 },
    Sit,
    Fall,
    Held,
    Thrown,
    Dizzy,
    Patted,
    Sleep,
    Carry,
    Exit,
    Enter,
    Peek,
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Event {
    ReachedDoor,
    Landed,
    PeekDone,
}

pub struct Pet {
    pub x: f32,
    pub y: f32,
    pub vx: f32,
    pub vy: f32,
    pub facing_left: bool,
    pub state: State,
    pub t: f32,
    pub frame: usize,
    pub angle: f32,
    owner_away: bool,
    walk_clock: f32,
}

impl Pet {
    pub fn new(x: f32, y: f32) -> Pet {
        Pet { x, y, vx: 0.0, vy: 0.0, facing_left: false, state: State::Idle, t: 0.0, frame: 0, angle: 0.0, owner_away: false, walk_clock: 0.0 }
    }

    fn set(&mut self, s: State) {
        self.state = s;
        self.t = 0.0;
    }

    pub fn pat(&mut self) {
        if !matches!(self.state, State::Held | State::Thrown | State::Fall | State::Carry | State::Exit | State::Enter) {
            self.set(State::Patted);
        }
    }
    pub fn grab(&mut self) {
        self.set(State::Held);
        self.vx = 0.0;
        self.vy = 0.0;
    }
    pub fn drag_to(&mut self, x: f32, y: f32) {
        if self.state == State::Held {
            self.x = x;
            self.y = y;
        }
    }
    pub fn throw(&mut self, vx: f32, vy: f32) {
        if self.state == State::Held {
            self.vx = vx.clamp(-3000.0, 3000.0);
            self.vy = vy.clamp(-3000.0, 3000.0);
            self.set(State::Thrown);
        }
    }
    pub fn set_owner_away(&mut self, away: bool) {
        self.owner_away = away;
    }
    pub fn carry_to_door(&mut self) {
        self.set(State::Carry);
    }
    pub fn exit_to_door(&mut self) {
        self.set(State::Exit);
    }
    pub fn enter_from_door(&mut self, world: &World) {
        self.x = world.door_x;
        self.y = world.ground();
        self.facing_left = true;
        self.set(State::Enter);
    }
    pub fn peek(&mut self) {
        self.set(State::Peek);
    }

    pub fn hitbox(&self, scale: f32) -> Rect {
        Rect { x: self.x - HALF_W * scale, y: self.y - 48.0 * scale, w: 32.0 * scale, h: 48.0 * scale }
    }

    fn walk_towards(&mut self, to_x: f32, dt: f32) -> bool {
        let d = to_x - self.x;
        self.facing_left = d < 0.0;
        let step = WALK_SPEED * dt;
        self.walk_clock += dt;
        self.frame = (self.walk_clock / FRAME_S) as usize % 8;
        if d.abs() <= step {
            self.x = to_x;
            true
        } else {
            self.x += step * d.signum();
            false
        }
    }

    fn supported(&self, world: &World) -> bool {
        world.floor_below(self.x, self.y).is_some_and(|f| (f - self.y).abs() < 1.0)
    }

    pub fn step(&mut self, dt: f32, world: &World, rng: &mut impl Rng) -> Option<Event> {
        self.t += dt;
        let left = world.screen.x + HALF_W;
        let right = world.screen.right() - HALF_W;
        match self.state {
            State::Held => None,
            State::Thrown | State::Fall => {
                self.vy += GRAVITY * dt;
                let old_y = self.y;
                self.x += self.vx * dt;
                self.y += self.vy * dt;
                if self.state == State::Thrown {
                    self.angle += self.vx.signum() * 12.0 * dt;
                }
                if self.x < left || self.x > right {
                    self.x = self.x.clamp(left, right);
                    self.vx = -self.vx * BOUNCE;
                }
                if self.y < world.screen.y + 48.0 {
                    self.y = world.screen.y + 48.0;
                    self.vy = self.vy.abs() * BOUNCE;
                }
                // Land on the first floor crossed while falling.
                if self.vy > 0.0
                    && let Some(f) = world.floor_below(self.x, old_y)
                    && self.y >= f
                {
                    self.y = f;
                    self.angle = 0.0;
                    self.vx = 0.0;
                    self.vy = 0.0;
                    let thrown = self.state == State::Thrown;
                    self.set(if thrown { State::Dizzy } else { State::Idle });
                    return Some(Event::Landed);
                }
                None
            }
            _ if !self.supported(world) && !matches!(self.state, State::Peek) => {
                self.set(State::Fall);
                None
            }
            State::Patted if self.t >= PAT_S => {
                self.set(State::Idle);
                None
            }
            State::Dizzy if self.t >= DIZZY_S => {
                self.set(State::Idle);
                None
            }
            State::Peek if self.t >= PEEK_S => {
                self.set(State::Idle);
                Some(Event::PeekDone)
            }
            State::Carry | State::Exit => self.walk_towards(world.door_x, dt).then(|| {
                self.set(State::Idle);
                Event::ReachedDoor
            }),
            State::Enter => {
                if self.walk_towards(world.door_x - 60.0, dt) {
                    self.set(State::Idle);
                }
                None
            }
            State::Sleep if !self.owner_away => {
                self.set(State::Idle);
                None
            }
            State::Idle | State::Sit | State::Wander { .. } if self.owner_away => {
                self.set(State::Sleep);
                None
            }
            State::Wander { to_x } => {
                if self.walk_towards(to_x, dt) {
                    self.set(if rng.random_bool(0.3) { State::Sit } else { State::Idle });
                }
                None
            }
            State::Idle if self.t > rng.random_range(2.0..6.0) => {
                let to_x = (self.x + rng.random_range(-300.0..300.0)).clamp(left, right);
                self.set(State::Wander { to_x });
                None
            }
            State::Sit if self.t > 8.0 => {
                self.set(State::Idle);
                None
            }
            _ => None,
        }
    }
}

//! Received files: safe names, no overwrites, and Mark-of-the-Web so Windows treats them as downloads.

use std::path::{Path, PathBuf};

const DANGEROUS: &[&str] = &["exe", "bat", "cmd", "ps1", "vbs", "js", "msi", "scr", "lnk"];
const RESERVED: &[&str] = &["CON", "PRN", "AUX", "NUL", "COM1", "COM2", "COM3", "COM4", "LPT1", "LPT2", "LPT3"];

pub fn is_dangerous(name: &str) -> bool {
    Path::new(name)
        .extension()
        .and_then(|e| e.to_str())
        .is_some_and(|e| DANGEROUS.contains(&e.to_ascii_lowercase().as_str()))
}

pub fn safe_name(name: &str) -> String {
    let last = name.rsplit(['/', '\\']).next().unwrap_or("");
    let cleaned: String = last.chars().filter(|c| !c.is_control() && !"<>:\"|?*".contains(*c)).collect();
    let cleaned = cleaned.trim().trim_matches('.').to_owned();
    if cleaned.is_empty() {
        return "file".into();
    }
    let stem = cleaned.split('.').next().unwrap_or("").to_ascii_uppercase();
    if RESERVED.contains(&stem.as_str()) { format!("_{cleaned}") } else { cleaned }
}

pub fn unique_path(dir: &Path, name: &str) -> PathBuf {
    let first = dir.join(name);
    if !first.exists() {
        return first;
    }
    let p = Path::new(name);
    let stem = p.file_stem().and_then(|s| s.to_str()).unwrap_or("file");
    let ext = p.extension().and_then(|s| s.to_str()).map(|e| format!(".{e}")).unwrap_or_default();
    (1..).map(|i| dir.join(format!("{stem} ({i}){ext}"))).find(|c| !c.exists()).expect("some free name")
}

pub fn save(dir: &Path, name: &str, bytes: &[u8], source_url: &str) -> std::io::Result<PathBuf> {
    std::fs::create_dir_all(dir)?;
    let path = unique_path(dir, &safe_name(name));
    std::fs::write(&path, bytes)?;
    #[cfg(windows)]
    {
        let mut ads = path.clone().into_os_string();
        ads.push(":Zone.Identifier");
        std::fs::write(ads, format!("[ZoneTransfer]\r\nZoneId=3\r\nHostUrl={source_url}\r\n"))?;
    }
    #[cfg(not(windows))]
    let _ = source_url;
    Ok(path)
}

pub fn downloads_dir() -> PathBuf {
    std::env::var_os("USERPROFILE").map(PathBuf::from).unwrap_or_else(std::env::temp_dir).join("Downloads").join("PetLink")
}
```

//! The connection to the relay: one thread with its own tokio runtime, reconnecting forever.

use crate::config::Config;
use crate::protocol::{Envelope, Msg, PROTOCOL, Person};
use futures::{SinkExt, StreamExt};
use std::path::PathBuf;
use std::time::Duration;
use tokio::sync::mpsc::{UnboundedReceiver, UnboundedSender, unbounded_channel};
use tokio_tungstenite::tungstenite::Message as WsMessage;

pub enum NetEvent {
    Connected { me: Person, friends: Vec<Person> },
    Disconnected,
    Message(Envelope),
    Upgrade,
    Uploaded { file_id: String },
    UploadFailed { file_id: String, error: String },
}

pub enum NetCmd {
    Send(Envelope),
    Upload { file_id: String, to: String, name: String, bytes: Vec<u8> },
    Shutdown,
}

pub struct Net {
    pub cmds: UnboundedSender<NetCmd>,
    pub events: std::sync::mpsc::Receiver<NetEvent>,
}

pub fn backoff(attempt: u32, jitter: f32) -> Duration {
    let base = 2f32.powi(attempt.min(6) as i32).min(60.0);
    if base >= 60.0 {
        return Duration::from_secs(60);
    }
    Duration::from_secs_f32(base * (0.8 + 0.4 * jitter.clamp(0.0, 1.0)))
}

pub struct Outbox {
    path: PathBuf,
    items: Vec<Envelope>,
}

fn mail_id(e: &Envelope) -> Option<&str> {
    match &e.msg {
        Msg::Mail { mail_id, .. } => Some(mail_id),
        _ => None,
    }
}

impl Outbox {
    pub fn open(path: PathBuf) -> Outbox {
        let items = match std::fs::read_to_string(&path) {
            Ok(text) => serde_json::from_str(&text).unwrap_or_else(|e| {
                tracing::warn!("outbox unreadable ({e}); moved aside");
                let _ = std::fs::rename(&path, path.with_extension("json.bad"));
                Vec::new()
            }),
            Err(_) => Vec::new(),
        };
        Outbox { path, items }
    }

    fn write(&self) {
        if let Err(e) = std::fs::write(&self.path, serde_json::to_vec(&self.items).unwrap_or_default()) {
            tracing::error!("couldn't save the outbox: {e}");
        }
    }

    pub fn push(&mut self, e: Envelope) {
        let Some(id) = mail_id(&e) else { return };
        if self.items.iter().any(|i| mail_id(i) == Some(id)) {
            return;
        }
        self.items.push(e);
        self.write();
    }

    pub fn remove_mail(&mut self, id: &str) {
        self.items.retain(|i| mail_id(i) != Some(id));
        self.write();
    }

    pub fn items(&self) -> &[Envelope] {
        &self.items
    }
}

pub async fn download(config: &Config, file_id: &str) -> anyhow::Result<Vec<u8>> {
    let r = reqwest::Client::new()
        .get(format!("{}/{file_id}", config.files_url()))
        .bearer_auth(&config.token)
        .send()
        .await?
        .error_for_status()?;
    Ok(r.bytes().await?.to_vec())
}

async fn upload(config: &Config, file_id: &str, to: &str, name: &str, bytes: Vec<u8>) -> anyhow::Result<()> {
    reqwest::Client::new()
        .put(format!("{}/{file_id}", config.files_url()))
        .query(&[("to", to), ("name", name)])
        .bearer_auth(&config.token)
        .body(bytes)
        .send()
        .await?
        .error_for_status()?;
    Ok(())
}

impl Net {
    pub fn start(config: Config, data_dir: PathBuf, wake: impl Fn() + Send + Sync + 'static) -> Net {
        let (cmd_tx, cmd_rx) = unbounded_channel();
        let (ev_tx, ev_rx) = std::sync::mpsc::channel();
        std::thread::Builder::new()
            .name("petlink-net".into())
            .spawn(move || {
                let rt = tokio::runtime::Builder::new_multi_thread().worker_threads(2).enable_all().build().expect("tokio runtime");
                rt.block_on(run(config, data_dir, cmd_rx, ev_tx, std::sync::Arc::new(wake)));
            })
            .expect("net thread");
        Net { cmds: cmd_tx, events: ev_rx }
    }
}

type Wake = std::sync::Arc<dyn Fn() + Send + Sync>;

async fn run(config: Config, data_dir: PathBuf, mut cmds: UnboundedReceiver<NetCmd>, events: std::sync::mpsc::Sender<NetEvent>, wake: Wake) {
    let emit = |e: NetEvent| {
        let _ = events.send(e);
        wake();
    };
    let mut outbox = Outbox::open(data_dir.join("outbox.json"));
    let mut attempt = 0u32;
    loop {
        match session(&config, &mut cmds, &emit, &mut outbox, &mut attempt).await {
            Ok(Stop::Shutdown) => return,
            Ok(Stop::Upgrade) => {
                emit(NetEvent::Upgrade);
                return;
            }
            Ok(Stop::Lost) => {}
            Err(e) => tracing::info!("relay connection failed: {e:#}"),
        }
        emit(NetEvent::Disconnected);
        let wait = backoff(attempt, rand::random());
        attempt += 1;
        // Keep accepting mail while offline; it waits in the outbox.
        let deadline = tokio::time::sleep(wait);
        tokio::pin!(deadline);
        loop {
            tokio::select! {
                _ = &mut deadline => break,
                cmd = cmds.recv() => match cmd {
                    None | Some(NetCmd::Shutdown) => return,
                    Some(NetCmd::Send(e)) => outbox.push(e),
                    Some(NetCmd::Upload { file_id, .. }) => emit(NetEvent::UploadFailed { file_id, error: "offline".into() }),
                },
            }
        }
    }
}

enum Stop {
    Shutdown,
    Lost,
    Upgrade,
}

async fn session(
    config: &Config,
    cmds: &mut UnboundedReceiver<NetCmd>,
    emit: &impl Fn(NetEvent),
    outbox: &mut Outbox,
    attempt: &mut u32,
) -> anyhow::Result<Stop> {
    let (ws, _) = tokio_tungstenite::connect_async(config.relay_url.as_str()).await?;
    let (mut tx, mut rx) = ws.split();
    let hello = Envelope::new("", Msg::Hello { token: config.token.clone(), client_version: option_env!("PETLINK_BUILD").unwrap_or("dev").into() });
    tx.send(WsMessage::text(serde_json::to_string(&hello)?)).await?;
    let mut uploads = tokio::task::JoinSet::new();
    loop {
        tokio::select! {
            frame = rx.next() => {
                let Some(frame) = frame else { return Ok(Stop::Lost) };
                let text = match frame? {
                    WsMessage::Text(t) => t,
                    WsMessage::Close(Some(c)) if u16::from(c.code) == 4426 => return Ok(Stop::Upgrade),
                    WsMessage::Close(Some(c)) if u16::from(c.code) == 4401 => anyhow::bail!("the relay refused the token"),
                    WsMessage::Close(_) => return Ok(Stop::Lost),
                    _ => continue,
                };
                let env: Envelope = match serde_json::from_str(&text) {
                    Ok(e) => e,
                    Err(e) => { tracing::warn!("unknown message from the relay: {e}"); continue }
                };
                if env.v != PROTOCOL { return Ok(Stop::Upgrade) }
                match &env.msg {
                    Msg::Welcome { me, friends } => {
                        *attempt = 0;
                        emit(NetEvent::Connected { me: me.clone(), friends: friends.clone() });
                        for item in outbox.items().to_vec() {
                            tx.send(WsMessage::text(serde_json::to_string(&item)?)).await?;
                        }
                    }
                    Msg::Error { code, .. } if code == "upgrade" => return Ok(Stop::Upgrade),
                    Msg::Delivered { mail_id } => { outbox.remove_mail(mail_id); emit(NetEvent::Message(env)) }
                    _ => emit(NetEvent::Message(env)),
                }
            }
            cmd = cmds.recv() => match cmd {
                None | Some(NetCmd::Shutdown) => { let _ = tx.send(WsMessage::Close(None)).await; return Ok(Stop::Shutdown) }
                Some(NetCmd::Send(e)) => {
                    outbox.push(e.clone());
                    tx.send(WsMessage::text(serde_json::to_string(&e)?)).await?;
                }
                Some(NetCmd::Upload { file_id, to, name, bytes }) => {
                    let config = config.clone();
                    uploads.spawn(async move {
                        let r = upload(&config, &file_id, &to, &name, bytes).await;
                        (file_id, r)
                    });
                }
            },
            Some(done) = uploads.join_next(), if !uploads.is_empty() => {
                if let Ok((file_id, r)) = done {
                    emit(match r {
                        Ok(()) => NetEvent::Uploaded { file_id },
                        Err(e) => NetEvent::UploadFailed { file_id, error: format!("{e:#}") },
                    });
                }
            }
        }
    }
}
```

Note `outbox.push` ignores non-mail messages, so `Send` of a touch/visit is fire-and-forget. The upload `JoinSet` is dropped (uploads cancelled) when the session ends; the UI shows those parcels as failed with Retry (spec §7).

`fn update(&mut self, ctx, frame)` each frame, in this order:
1. `while let Ok(ev) = self.net.events.try_recv()` → handle (Connected → set me/friend, `friend_online`, `friend_peek`, rebuild visitor sprites with friend's hue; Disconnected → `friend_online = false`, drop visitor; Message(env) → dispatch by `env.msg`, see table below; Upgrade → `self.bubble("Please update PetLink")`; Uploaded/UploadFailed → update `outgoing`).
2. `if let Some(a) = self.tray.poll()` → handle.
3. Every 250 ms: `self.world = World::build(win::screen(), win::taskbar(), &win::top_windows(), win::tray_left())` with all rects divided by `ctx.pixels_per_point()` (egui works in points).
4. Presence: `let away = win::idle_seconds() >= 300;` if changed, send `Presence { state: Away/Online }` to `""` (broadcast) and `self.mine.set_owner_away(away)`.
5. Step pets with `dt = ctx.input(|i| i.stable_dt).min(0.05)`; handle `Event::ReachedDoor` for my pet: if carrying → send the mail (`NetCmd::Send`) and set `my_pet_away_until_return = Instant + 1.5s`, then `enter_from_door`; if `exit_to_door` for visit → `my_pet_away = true` (not drawn) and send `VisitStart`; for the visitor: when it reaches the door after its job → remove it.
6. Hit test: `let (cx, cy) = win::cursor()` (convert to points); `let over = [mine hitbox, visitor hitbox, door rect, parcel rects].any(contains)`; if `over == self.passthrough` (i.e. needs change) → `ctx.send_viewport_cmd(egui::ViewportCommand::MousePassthrough(!over))`, `self.passthrough = !over`. While dragging, keep passthrough off.
7. Hide while fullscreen: if `win::foreground_is_fullscreen()` draw nothing this frame.
8. Draw on `egui::CentralPanel::default().frame(egui::Frame::NONE)`: the door (a 20×28 px brown rect with a yellow knob; lit = warm yellow glow rect behind it when `friend_online`), parcels (`parcel.png` texture at ×scale), my pet (unless `my_pet_away`), the visitor. Texture choice: Wander/Carry/Exit/Enter → walk frame `pet.frame` (mirrored when `facing_left`), Carry → `carry.png` while walking (spec: carry pose), Sit → sit, Sleep → sleep + a "z" `painter.text` drifting up, everything else → idle. Patted: draw scaled `1.0 + 0.15*sin(t*20)` vertically + a red "♥" above. Dizzy: three "✦" circling the head. Thrown/Fall: rotate the idle texture by `pet.angle` (`egui::Image::new(..).rotate(angle, Vec2::splat(0.5))`). Peek: idle + a magnifier drawn with the painter (circle stroke 2 px + handle line) at the hand.
   Load textures with `ctx.load_texture(name, ColorImage::from_rgba_unmultiplied(...), TextureOptions::NEAREST)`.
9. Input on the overlay (only reaches us when passthrough is off): a press on a pet starts `drag`; moving > 4 px → `pet.grab()` + `drag_to`; release after a drag → `throw` with velocity from the last 80 ms of positions; a click without a drag → `pet.pat()` and, if it's the visitor, `NetCmd::Send(Touch { what: Pat })`; a yeet of the visitor sends `Touch { what: Yeet }`. A click on the door opens the door menu (`egui::Area` popup with: Write letter…, Peek (disabled unless `friend_online && friend_peek`), Send to visit / Call home). A click on a parcel opens it (Task 11). `ctx.input(|i| i.raw.dropped_files.clone())` while the cursor is over my pet → open the compose window with those files attached.

| Msg | Effect |
|---|---|
| `Presence{state}` | `friend_online = state != Offline`; friend away → visitor (if any) `set_owner_away(true)` |
| `PeekAllow{on}` | `friend_peek = on` |
| `Mail{..}` | spawn visitor at the door in Carry state walking to `door_x - 80`, drop a `Parcel` there on arrival, then exit through the door |
| `MailRead{..}` | my pet does a little hop (`pat()`) |
| `Delivered{..}` | remove from `outgoing` |
| `PeekRequest{peek_id}` | if `!my_peek` → reply `PeekResult{denied:true}`; else spawn visitor with `peek()`, and on `Event::PeekDone` run the capture (Task 12) |

| `Touch{what}` | a small bubble over my door: "<name> patted/poked/yeeted your pet" |
| `Error{code,message,..}` | bubble with `message`; `offline` during peek/visit brings my pet home |

```rust
//! Self-update from this repo's node-build-N releases (the same feed as kerneld).

use anyhow::{Context, bail};
use serde::Deserialize;
use sha2::{Digest, Sha256};
use std::time::Duration;

pub const REPO: &str = "Lithium-16/Kernel-Hub";
pub const ASSET: &str = "petlink-windows-x64.exe";
const EVERY: Duration = Duration::from_secs(6 * 3600);

#[derive(Debug, Deserialize)]
pub struct GhRelease {
    pub tag_name: String,
    pub draft: bool,
    pub prerelease: bool,
    pub assets: Vec<GhAsset>,
}

#[derive(Debug, Clone, Deserialize)]
pub struct GhAsset {
    pub name: String,
    pub browser_download_url: String,
}

pub struct Release {
    pub build: u32,
    pub exe: GhAsset,
    pub sha: GhAsset,
}

pub fn pick_latest(releases: Vec<GhRelease>) -> Option<Release> {
    releases
        .into_iter()
        .filter(|r| !r.draft && !r.prerelease)
        .filter_map(|r| {
            let build = r.tag_name.strip_prefix("node-build-")?.parse().ok()?;
            let find = |n: &str| r.assets.iter().find(|a| a.name == n).cloned();
            Some(Release { build, exe: find(ASSET)?, sha: find(&format!("{ASSET}.sha256"))? })
        })
        .max_by_key(|r| r.build)
}

pub fn current_build() -> Option<u32> {
    option_env!("PETLINK_BUILD")?.parse().ok()
}

fn old_path() -> Option<std::path::PathBuf> {
    Some(std::env::current_exe().ok()?.with_file_name("petlink.old.exe"))
}

pub fn cleanup_old() {
    if let Some(p) = old_path() {
        let _ = std::fs::remove_file(p);
    }
}

pub fn spawn_checker() {
    if current_build().is_none() {
        tracing::info!("dev build: no self-update");
        return;
    }
    std::thread::Builder::new()
        .name("petlink-update".into())
        .spawn(|| loop {
            match check_now() {
                Ok(true) => std::process::exit(0),
                Ok(false) => {}
                Err(e) => tracing::warn!("update check failed: {e:#}"),
            }
            std::thread::sleep(EVERY);
        })
        .expect("update thread");
}

pub fn check_now() -> anyhow::Result<bool> {
    let Some(current) = current_build() else { return Ok(false) };
    let rt = tokio::runtime::Builder::new_current_thread().enable_all().build()?;
    rt.block_on(async {
        let client = reqwest::Client::builder().user_agent("petlink").timeout(Duration::from_secs(120)).build()?;
        let releases: Vec<GhRelease> = client
            .get(format!("https://api.github.com/repos/{REPO}/releases?per_page=30"))
            .send()
            .await?
            .error_for_status()?
            .json()
            .await?;
        let Some(latest) = pick_latest(releases) else { return Ok(false) };
        if latest.build <= current {
            return Ok(false);
        }
        let want = client.get(&latest.sha.browser_download_url).send().await?.error_for_status()?.text().await?;
        let want = want.split_whitespace().next().context("empty .sha256")?.to_ascii_lowercase();
        let exe = client.get(&latest.exe.browser_download_url).send().await?.error_for_status()?.bytes().await?;
        if hex::encode(Sha256::digest(&exe)) != want {
            bail!("downloaded build {} doesn't match its SHA-256", latest.build);
        }
        let me = std::env::current_exe()?;
        let old = old_path().context("no exe path")?;
        let _ = std::fs::remove_file(&old);
        std::fs::rename(&me, &old).context("moving the running exe aside")?;
        if let Err(e) = std::fs::write(&me, &exe) {
            let _ = std::fs::rename(&old, &me);
            return Err(e).context("writing the new exe");
        }
        std::process::Command::new(&me).spawn().context("starting the new version")?;
        tracing::info!("updated to build {}", latest.build);
        Ok(true)
    })
}
```

The single-instance mutex is held by the old process until it exits; the new process may start first. In `main`, retry `single_instance()` for up to 5 s (10 × 500 ms) before giving up, so the restart after an update isn't lost.
