# Drama Club picture backgrounds

The `*.webp` files in this folder (and their `*.thumb.webp` thumbnails) are visual-novel
backgrounds supplied by the repository owner for Drama Club, resized to 1280x720 (thumbnails
320x180). They are not covered by this repository's code license; check with the owner before
reusing them elsewhere. The other Drama Club backgrounds are drawn in code in `../scenes.js`.
